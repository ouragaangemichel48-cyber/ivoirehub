Sécurité Ivoirehub

Mesures pour protéger les utilisateurs et la plateforme.

Protection des données

  • Ne partagez jamais votre mot de passe
  • Les échanges sensibles passeront par le serveur sécurisé (HTTPS) en production
  • Localisation GPS : demandée uniquement avec votre accord

Anti-fraude & bonnes pratiques

  • Vérifiez les profils (badge vérifié quand disponible)
  • Préférez les paiements traçables (Wave, etc.)
  • Ne payez pas hors plateforme pour des montants élevés sans preuve
  • Signalez tout comportement suspect

Sécurité des paiements

  • Wave, Orange Money, MTN, Moov : validation sur votre téléphone (PIN), Ivoirehub ne voit pas votre code secret
  • Visa / Mastercard : en production via prestataire certifié ; CVV jamais stocké chez nous
  • Chaque paiement a une référence unique (IH-…)
  • Plafonds et contrôles de montant anti-fraude
  • Historique consultable dans Espace Pro

Aujourd’hui : simulation sécurisée côté navigateur. Demain : API marchands officielles + HTTPS.

Techniques actives sur ce site

  • Échappement HTML (protection XSS) sur les contenus affichés
  • Validation téléphone / prix / textes à la saisie
  • Limitation de longueur des champs
  • Session navigateur + déconnexion manuelle
  • Images en lazy-load / referrer restreint

À venir (backend)

  • Mots de passe hashés (bcrypt)
  • Tokens JWT + expiration
  • HTTPS obligatoire
  • Rate limiting anti-spam
  • Modération des annonces
